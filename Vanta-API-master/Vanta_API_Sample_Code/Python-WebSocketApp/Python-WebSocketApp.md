This is an example application which shows how to use the API in Python and create a GUI which allows you to monitor and control some of the functions of the Vanta iX through API calls.

The GUI elements of the Python code are done using 'PyQT5' and its dependencies.
The spectrum display uses 'pyqtgraph'

You may need to install the dependencies that this script needs using pip or the configuration tools in your IDE.

    pip install PyQT5
    pip install pyqtgraph
    pip install websocket-client

We recommend using Python 3.7, as this is what was used to develop and test this code. 
A good example of an IDE is PyCharm by Jetbrains https://www.jetbrains.com/pycharm/ The PyCharm IDE allows the creation of virtual environments which help separate the packages that you will need to install from others that you might already have.
