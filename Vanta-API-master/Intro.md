# Vanta-API
Vanta websockets API documentation and sample code.
----
>See the document [Olympus-XRF-API.md](Vanta_API_Documents/Olympus-XRF-API.md) for an overview of the Vanta API

>See the document [API-Command-List.md](Vanta_API_Documents/API-Command-List.md) for a comprehensive list of Vanta API commands

>Inside the [Vanta API Sample code](Vanta_API_Sample_Code) directory you will find sample code in [C++](Vanta_API_Sample_Code/SampleApplication) 
>and [Python](Vanta_API_Sample_Code/Python-WebSocketApp/Python-WebSocketApp.md)
>The C++ code is a very simple example showing how to make a connection to a unit with the Vanta API and to start a test.  If you want a more advanced example of how to handle different types of messages see the python example.
